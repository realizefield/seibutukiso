BL03 陽性植物と陰性植物・陽葉と陰葉

1. 陽性植物と陰性植物のちがい

植物の中には、強い光を好むものと、弱い光でも生きていけるものがあります。

  • 陽性植物（ようせいしょくぶつ）：強い光を好み、明るい場所でよく育つ。
  • 陰性植物（いんせいしょくぶつ）：弱い光でも育ち、林の中など暗い場所でも生きられる。

この2種類の植物の光合成速度を、光の強さに対してグラフにくらべると、特徴がよくわかります。

4. 陽葉と陰葉（同じ植物でも葉が変わる）

同じ植物でも、生えている場所の光の強さによって、葉のつくりが変わります。

  • 陽葉（ようよう）：木の上の方や、日当たりのよい場所の葉。厚くて小さく、濃い緑色。
  • 陰葉（いんよう）：木の下の方や、日当たりの悪い場所の葉。薄くて大きく、薄い緑色。
陽葉と陰葉の特徴
項目 陽葉 陰葉
厚さ 厚い 薄い
大きさ 小さい 大きい（光を多く受け取るため）
光合成速度 大きい 小さい
光飽和点 大きい 小さい
覚え方

「陽（よう）は厚くて濃い／陰（いん）は薄くて大きい」
（日当たりがよい葉は丈夫に厚く、暗い場所の葉は光をできるだけ集めるため大きく広がる）

5. 用語まとめ
陽性植物
強い光を好む植物。補償点・光飽和点・最大光合成速度・呼吸速度がすべて大きい。例：イネ、ススキ、クロマツ
陰性植物
弱い光でも生きられる植物。すべての値が小さい。例：コケ、シダ、アオキ
陽葉
日当たりのよい場所の葉。厚くて小さく濃い緑色。
陰葉
暗い場所の葉。薄くて大きく薄い緑色。

⚡ ミニテスト（2問）― すぐに確認しよう！
1 陽性植物と陰性植物を比べたとき、正しい記述を①〜④から選べ。
  • ①陰性植物は補償点が大きく、弱い光では生育できない。
  • ②陽性植物は補償点も光飽和点も大きく、強い光でよく育つ。
  • ③陰性植物は光飽和点が陽性植物より大きい。
  • ④陽性植物の呼吸速度は陰性植物より小さい。
✅ 正解：②
陽性植物は補償点・光飽和点・最大光合成速度・呼吸速度がすべて大きく、強い光の場所でよく育ちます。①は逆（陰性植物は補償点が小さい）。③は逆（光飽和点は陽性植物の方が大きい）。④も逆（陽性植物の呼吸速度の方が大きい）。
2 コケ・シダ・アオキの組み合わせとして正しいものを①〜④から選べ。
  • ①すべて陽性植物で、明るい場所を好む。
  • ②すべて陰性植物で、弱い光でも育つ。
  • ③コケは陽性植物、シダとアオキは陰性植物である。
  • ④すべて陽葉をもつ植物である。
✅ 正解：②
コケ・シダ・アオキはいずれも陰性植物の代表例で、林の中などの弱い光でも生育できます。対して陽性植物の例はイネ・ススキ・クロマツ・ヒマワリなどです。

例題・類題（グラフ読み取り：高認形式）
例題
次の会話文を読み、問い（問1〜問3）に答えよ。

先　生：スギの森の中は、夏でも地面まで光がほとんど届かないため、とても薄暗いですね。

生　徒：そういえば、スギ林の中には緑の苔が生えていますが、イネのような草はほとんどありませんね。

先　生：よく気づきましたね。図のグラフを使って考えてみましょう。スギ林の林床のような弱い光の環境でも育てる植物は ウ で、イネのように強い光を好む植物は エ です。

生　徒：なるほど。スギ林の林床の光の強さが図の オ くらいだとすると、イネが生育できない理由がわかります。

図：A＝強い光を好む植物、B＝弱い光でも育つ植物の光合成曲線。C・D・Eは光の強さの位置を示す。
問1．会話文中の空欄 ウ に入る最も適切な語句を①〜④から選べ。
  • ①陽性植物
  • ②陰性植物
  • ③植物A
  • ④陽葉をもつ植物
✅ 正解：②　陰性植物
スギ林の林床は光が弱い環境です。このような弱い光でも補償点をこえて光合成ができ、生育できるのは陰性植物（グラフのB）です。陰性植物は補償点・光飽和点ともに小さく、暗い場所でも有機物を積み上げられます。
問2．会話文中の空欄 エ に入る最も適切な語句を①〜④から選べ。
  • ①陰性植物
  • ②植物B
  • ③陽性植物
  • ④陰葉をもつ植物
✅ 正解：③　陽性植物
イネは強い光を好む陽性植物（グラフのA）です。補償点・光飽和点が大きく、十分な光がないと光合成速度が呼吸速度を上回れません。スギ林の薄暗い林床では生育できません。
問3．会話文中の空欄 オ に入るものとして最も適切なものを①〜④から選べ。
  • ①C（陰性植物の補償点よりも弱い光）
  • ②D（陰性植物の補償点と陽性植物の補償点の間）
  • ③E（陽性植物の光飽和点付近）
  • ④CよりもさらにCO₂吸収速度が大きい場所
✅ 正解：①　C
スギ林の林床は非常に光が弱く、陰性植物（B）の補償点よりも光が弱い位置 C が該当します。
Cの光の強さでは、陰性植物Bですらまだ呼吸速度の方が大きく（グラフ上でゼロラインより下）、陽性植物Aはさらに大きなCO₂放出状態です。つまりイネ（陽性植物）は光合成で有機物を積み上げられず、生育できません。
※ DではBの補償点に近く陰性植物が辛うじて生育できる光量、Eは十分に明るい環境です。
類題
次の会話文を読み、問い（問1〜問3）に答えよ。

先　生：高いビルの北側には、一日中ほとんど直射日光が当たりません。そのような日陰の地面には、特定の植物しか育ちませんね。

生　徒：確かに、日陰の地面にはドクダミやコケは生えていますが、ヒマワリやイネは育ちません。

先　生：そうです。図のグラフで考えると、このような日陰でも育てる植物は ア で、ヒマワリのように強い光を必要とする植物は イ です。

生　徒：日陰の光の強さが図の ウ の位置だとすると、ヒマワリが育てない理由がグラフから説明できます。

図：P＝強い光を好む植物、Q＝弱い光でも育つ植物の光合成曲線。X・Y・Zは光の強さの位置を示す。
問1．会話文中の空欄 ア に入る最も適切な語句を①〜④から選べ。
  • ①陽性植物
  • ②植物P
  • ③陰性植物
  • ④陽葉をもつ植物
✅ 正解：③　陰性植物
日陰（弱い光）でも育てるのは陰性植物（グラフのQ）です。ドクダミやコケは陰性植物の代表例で、弱い光でも補償点をこえて光合成でき、有機物を蓄積できます。
問2．会話文中の空欄 イ に入る最も適切な語句を①〜④から選べ。
  • ①陰性植物
  • ②陽性植物
  • ③植物Q
  • ④陰葉をもつ植物
✅ 正解：②　陽性植物
ヒマワリは強い光を好む陽性植物（グラフのP）です。補償点が大きく、弱い光では呼吸速度の方が光合成速度を上回るため、日陰では生育できません。
問3．会話文中の空欄 ウ に入るものとして最も適切なものを①〜④から選べ。
  • ①Z（強い光）
  • ②Y（陰性植物の補償点と陽性植物の補償点の間）
  • ③X（陰性植物の補償点より弱い光）
  • ④陽性植物の光飽和点の位置
✅ 正解：③　X
ビルの日陰は極めて光が弱く、陰性植物（Q）の補償点よりも弱い位置 X が該当します。
X の光の強さでは、陰性植物 Q も CO₂ を放出している状態（補償点以下）で、陽性植物 P はさらに大きな放出量となります。そのため、ヒマワリ（陽性植物）はここでは光合成が呼吸に追いつかず、生育できないことがグラフから読み取れます。
Y では陰性植物の補償点付近なので Q は辛うじて生育できますが P はまだ生育困難。Z は十分に光が強い環境です。
